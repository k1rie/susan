RESUMEN HONESTO
  SI se verifico:
    - El sketch estacion_aula.ino COMPILA Y ENLAZA para Arduino UNO (ATmega328P,
      16 MHz) con avr-gcc 7.3.0, el nucleo "Arduino AVR Boards" 1.8.6 y las
      librerias REALES MFRC522 1.4.12 y LiquidCrystal_I2C 1.1.4. El codigo propio
      se compilo con -Wall -Wextra: 0 errores y 0 avisos.
    - Uso de memoria (ver abajo): flash 14122 B de 32256 (43,1 %); SRAM estatica
      1227 B de 2048 (59,9 %), quedan unos 820 B para pila y monton.
    - El binario compilado se EJECUTO en el simulador de instrucciones simavr
      (ver el segundo bloque): HELLO, PING/PONG, entradas hostiles, boton, LED,
      tono de arranque y regla de 30 s. Es un modelo minimo: sin LCD (no hay
      esclavo I2C), sin tarjetas RFID, MFRC522 reducido a un esclavo SPI que solo
      contesta VersionReg y "sin tarjeta".
  NO se verifico:
    - Nada en hardware fisico: no se grabo en ninguna placa, no se conecto
      ningun MFRC522, LCD, LED, zumbador ni pulsador reales.
    - No se uso arduino-cli ni el IDE de Arduino. El binario sale de un build
      MANUAL que replica las banderas del platform.txt del nucleo 1.8.6; el
      compilador de Ubuntu (gcc-avr 1:7.3.0+Atmel3.7.0-1) no es identico al que
      empaqueta el IDE, asi que el tamano exacto puede variar unos bytes.
    - La version de LiquidCrystal_I2C usada es la rama master de
      marcoschwartz/LiquidCrystal_I2C (1.1.4); el Administrador de bibliotecas
      puede ofrecer otra version del mismo autor original. El sketch solo usa
      constructor(dir, cols, filas), init(), backlight(), clear(), setCursor() y
      print(), presentes en ambas.
    - "Compila" no implica "funciona": ver README.md (tabla de estado).

RUTAS PARA OBTENER arduino-cli QUE SE INTENTARON (todas desde este entorno)
    - github.com/arduino/arduino-cli/releases (y api.github.com): el proxy de
      salida responde 403.
    - downloads.arduino.cc (instalador oficial, indices de paquetes y de
      librerias): sin conexion; el proxy registra 403 para arduino.cc.
    - PlatformIO (dl.platformio.org, registry.platformio.org): sin conexion.
    - PyPI: no hay paquete "arduino-cli" (pip: "No matching distribution").
    - npm: el paquete "arduino-cli" es solo un envoltorio JavaScript que exige
      tener ya el binario instalado; no lo incluye.
    - Si alcanzaron: los repositorios de Ubuntu (apt) y raw.githubusercontent.com.
  Por eso se uso la ruta (b) del encargo, mejorada: paquetes de Ubuntu gcc-avr,
  avr-libc, binutils-avr y arduino-core-avr (el nucleo real, no stubs) y las
  librerias reales bajadas de raw.githubusercontent.com (MFRC522 por la etiqueta
  1.4.12; LiquidCrystal_I2C por master, con sha256 fijados en el script). No
  hay cabeceras falsas: lo que se comprobo es la compilacion contra el codigo
  fuente real de las dos librerias y del nucleo.

COMO REPETIRLO
    sudo apt install gcc-avr avr-libc binutils-avr arduino-core-avr
    firmware/compilar-avr.sh [directorio_de_trabajo]
    sudo apt install libsimavr-dev        # solo para la ejecucion en simavr
    firmware/pruebas/simavr/ejecutar-simavr.sh <directorio>/build/estacion_aula.elf
  Con acceso normal a internet basta:
    arduino-cli compile --fqbn arduino:avr:uno firmware/estacion_aula
